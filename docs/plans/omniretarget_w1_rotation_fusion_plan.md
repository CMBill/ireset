## 3. 唯一候选及其数学契约

协议名称：`w1_rotation_path_nlerp_v2`。本轮只登记这一候选；此前的全贡献短弧SLERP作为历史机制对照，不作为另一可择优方案。

### 3.1 输入、权重与不变量

输入为原生成器一次采样的实际解码 `pos[N,F,3] / quat[N,F,4] / joints[N,F,29]`、真实starts、T、stride和frame_dt。仅使用推理可得的预测窗口；不读取教师根/关节、未来真值或质量指标来选择路径。

本轮固定F=60、stride=30，starts来自原 `window_starts`。每窗权重逐位复用原 `window_weight`，包括非整stride末窗。starts必须严格递增、首帧0、末帧完整覆盖；逐帧权重和须正且有限。输入数组形状、有限性、整数参数和四元数范数先核验，拒绝bool冒充计数；范数误差上限1e-5沿用现行解码契约。

位置和关节直接复用原融合函数的输出，不改变计算顺序、dtype或舍入；其逐位不变是硬门。旋转内部在独立副本上升为float64并单位化，原decoded数组不改写。零权重条目不参与路径激活、加权和或稳定性计算；其原输入仍须满足完整解码工件的有效性契约。

### 3.2 窗口内提升与窗口间固定符号

1. 每窗首四元数采用确定符号：绝对值最大分量为正，平局按w/x/y/z顺序。此后沿窗时间递推，若与前帧内积为负则整体翻转符号，使单窗表示连续。
2. 若某次相邻内积绝对值≤1e-6，即对应约180°的局部路径歧义，记 `window_lift_ambiguous`，保留原窗/帧证据，停止该候选的可消费声明；不假定这种大跳变是合法低速动作。
3. 按全局帧顺序处理。首窗在frame0激活。后续窗只在其权重首次大于0时激活，以**前一帧已融合的预测四元数**为参考，选择该窗的整体符号，使激活帧内积为正；此整体符号对该窗剩余全部时间固定。
4. 激活内积绝对值≤1e-6记 `window_activation_ambiguous`。新窗权重为0时既不选符号也不改变已有输出。多个同时激活者按start排序，统一对前一帧参考选符号，不能使用循环中尚未定案的当前帧均值。
5. 一经激活，不因后续窗间内积跨零而重新选择符号。每窗在全局路径上的符号、激活帧、激活内积及窗口内翻转记录全部入册。

四元数整体符号是表示选择，不改变该窗物理旋转。这里固定的是预测路径上的提升，不能用逐帧 `abs(dot)` 再次改回最短弧。

### 3.3 全贡献加权及退化处理

对全局帧t，令有效窗的归一化权重 `alpha_i(t)=w_i(t)/sum(w(t))`，固定符号后的单位四元数为 `q_i(t)`：

```text
u(t) = sum_i alpha_i(t) * q_i(t)
q_fused(t) = u(t) / ||u(t)||
```

所有正权重窗均参与，包括三窗覆盖时的中间窗。固定符号和非退化加权和避免逐帧最短弧的分支切换。它是路径相关的归一化四元数加权融合，不宣称唯一的SO(3)均值；NLERP的角速度参数化与旧SLERP不同，**两窗逐位等同旧SLERP不是v2的不变量**，该变化通过独立协议和质量比较如实计入。

注册稳定性门为 `||u(t)|| >= 0.5`：归一化映射的局部增益上界为2。小于0.5记 `quaternion_blend_ill_conditioned`，等于0.5合法；这是实施前的条件数选择，不是从新质量数据调出来的门槛。1e-6内积歧义门仅用于路径不可判定，二者不得混用。无正权重、NaN/Inf或坏范数均显式拒绝，禁止以epsilon分母或单位姿态把坏输入洗成有效输出。

使用NumPy求和/范数和SciPy Rotation进行姿态换序、复合及SO(3)角度核验，无新依赖、无通用流形优化器。四元数提升与归一化加权是本项目所需的最小补充；现有SciPy Slerp逐帧选择最短弧，不能仅靠四元数符号预翻转实现上述固定路径契约。

### 3.4 时间检查、拒收与产物状态

完整可计算候选保存后，逐帧计算 `omega(t)=||log(R(t-1)^T R(t))||/frame_dt`，使用原注册根角速度门7rad/s；30fps下约13.369°/步。单窗本身的坏跳变必须保留，禁止用速度裁剪、平滑或投影掩盖。窗口自身、融合前后及seam/非seam全局最坏帧分别报告。

分列 `numerical_valid`、`fusion_math_valid`、`fusion_temporal_pass`、原验收器的robot/task/raw通过状态，以及最终 `consumer_eligible`。角速度超限是质量失败，不能改记为数值失败并触发重采样。质量失败的完整raw仍保存为诊断证据；不能返回声称可消费的轨迹。

若路径/加权退化导致整段不可计算，保存输入、已算前缀、首个拒收帧和原因，指标记缺测量，不能用0补齐。拒收是诚实出口，但不等于已成功修复该段，亦不能作为提升接受率的样本筛选手段。
