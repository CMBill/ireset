依据:[Astra 审阅](../review/m2_m3_completion_failure_analysis_astra.md)、[Codex 审阅](../review/m2_m3_completion_review_codex.md)、[GLM 审阅](../review/m2_m3_completion_gate_analysis_glm.md)、[Kimi 审阅](../review/m2_m3_stage_gate_analysis_kimi.md)。实现与尝试级日志支持前两份关于正确性缺陷的结论。后两份关于串联瓶颈、路径约束和认证质量的建议保留为条件策略,其“输入不可恢复/剩余均非实现问题”归因不作为执行依据。

## 1. 目标、门禁与边界

1. 修复已确认缺陷,使约束语义、QP 模型、非线性验收、日志和统计一致。
2. 固定原六段完整轨迹,争取至少 4/6 保留;sub10/sub8 必须继续保留。达到数量与质量门后即进入 train24,不为追求 6/6 无限制调参。
3. train24 至少 18/24 保留并完成标签质量判断后,推进 312 originals 与 M3 重训。M2 性能/扰动验收独立记录,M4 最终评测另行安排。

冻结 strict 碰撞、限位、速度、手足验收阈值、插值采样协议及任务工作门 0.40;筛选沿用每个适用手侧几何接近覆盖 >=50%、参考抓取帧至少 10 帧的现有规则。0.40 为诊断工作门,不等于主方案最终任务质量达标。任务门重标留到 train24,不能与本轮实现修复混跑。

源教师、箱轨迹、fps、演示分母和数据划分不变。禁止裁掉失败帧、改变时间采样、放宽认证进入速度或删除困难演示来提高比例。预注册排除仍计入原始分母。使用项目 Python 3.12 与 `uv run --locked`;当前不新增依赖、不切换求解器或构建通用优化框架。

## 4. F1:pair 语义与所有成功返回复核

涉及 `repair/scp.py`、`repair/pipeline.py`、必要的 `constraints.py` 行装配。

- [ ] 以现有静态注册表为几何类别唯一来源。稳定 pair 身份与 `regen/collision` 行角色分开;回流只携带身份与发现位置,不允许行标签覆盖几何类别。未知 pair 显式报错,保持注册表方向约定。
- [ ] 同状态重复检查和回流后,最近手部几何选择、上下界不变;真实状态变化导致换选时保存原因。扫描、merit、QP 和 acceptance 使用同一语义。
- [ ] 修正行预算与去重:regen 占位只计算一次;已发现 pair 不因切片/重复占位丢失。超过预算时记录具体遗漏身份,扩容或明确拒绝,不能只记录一个计数后继续成功。
- [ ] 为提前成功、预算耗尽、trust 收缩和历史 best 统一成功复核。复核重新 forward 到拟返回状态,扫描完整注册表并检查全部适用约束;成功检查不受 QP 活跃行上限裁剪。发现新违反时使 best 失效并反馈求解,预算不足则明确失败。

## 5. F2:修正 QP 目标与物理增量的一致性

涉及 `repair/scp.py::build_qp/evaluate/objective`、`constraints.py::tangent_error` 与数值测试。

变量保持 35 维物理切空间增量 `xi=(dp,dtheta_world,dq)`。残差 `r=e/D`,其线性化应为 `r(xi)=r(0)+J_r xi`;统一按 `P += 2w J_r.T J_r`、`q += 2w J_r.T r` 装配。平移/关节加性部分 `J_r=diag(1/D)`,故线性项为 `2we/D^2`,不能再对已归一化的 r 乘 `D^-2`。

- [ ] prediction 与 temporal 均修复;包括 `z_prev=None`、非零残差及非单位权重。保持初始权重不变,不以重调 D 或权重抵消错误。
- [ ] 核查世界系旋转残差在实际 `retract_batch` 下的雅可比。优先复用项目旋转适配层/成熟 API;能力不足时用最小 SO(3) 补充并对拍。不能仅用加性分量通过推断完整流形模型正确。
- [ ] 对隔离项和组合目标检查 q 与零增量处实际 objective 梯度一致;检查 P 对应残差 Gauss-Newton 二次项。regularization 是步长阻尼,单独记录,不误当成状态目标 Hessian。
- [ ] float64 下覆盖小/中等根旋转、平移及关节偏移,中心差分步长 `1e-6` 并以 `1e-5/1e-7` 检查稳定区间。光滑用例预期梯度 `atol=1e-6, rtol=1e-4`;奇异/分支点单列,不能事后放宽阈值掩盖方向或单位错误。

验收:两跟踪项的数学契约通过;原 50x/10x 反例消失。所有历史依赖该目标的性能/接受率只保留为旧版本结果,新共享修复需标准模式重测。

## 7. F4:按新失败机制增加最小策略

### 7.1 路径碰撞优先:探测点约束

触发条件:B3 仍出现端点合法但转移碰撞。现有 sub16、sub12 仅作为候选反例,必须重放新状态链确认。

- [ ] 缓存违规 pair、alpha、固定前帧机器人/箱姿及当前箱姿。约束为 `d(interpolate(scene_prev, scene_end(xi), alpha)) >= lo`。前帧保持固定,箱体按原轨迹插值;不能把端点距离雅可比直接用作探测点雅可比,也不能默认旋转项简单乘 alpha。
- [ ] 先用现有插值和 retract 的中心差分获得可信复合梯度,再视 profile 使用解析链式法则优化。固定 pair/alpha 做线性化,每次接受步重算距离、梯度及自适应探测位置;碰撞特征切换时重新线性化并用非线性检查裁决。
- [ ] 探测行只加入碰撞下界,保持阶段 2 的端点闭合上界语义。单独布局并计数探测行,避免挤掉端点/锚点行;超限明确拒绝或扩容。
- [ ] 探测违反进入 SCP merit 与候选检查,不能只装 QP 而让线搜索使用不同目标。求解退出前按完整场景重新探测,独立终检协议不变。

验证:固定光滑最近特征的 robot-box/self 距离梯度对拍,覆盖根旋转、箱旋转、不同 alpha 和非零端点增量;预期 `atol=1e-5, rtol=1e-3`,非光滑点单列检查不作错误梯度通过。真实 sub16 反例和合法 30mm->24mm 接近必须同时验证。单项实验为 `B3+probe`,再重跑六段。

### 7.2 抓握稳定性:先定位,后软目标

触发条件:sub10/sub8 质量未恢复,或新增 keep 高接近覆盖但零认证。

- [ ] 先排除走廊消失、目标尺度及几何体换选;分析进入、稳定搬运、尾部释放分别失败于距离、速度还是锚漂。按真实三 site 的箱体系运动检查,不能只看质心。
- [ ] 在参考 hold 内构造参考驱动的箱系手部稳定软目标。优先惩罚相对参考手部运动增量的偏差,参考准静态时抑制额外抖动;不把所有手部运动强制为零,不引入 regrasp 新任务或复活已失败的统一速度硬行。
- [ ] 目标启用、退出与尺度须明确;如果采用零运动稳定段,由参考侧证据决定并在切换时记录,不得为制造认证而从机器人输出挑容易帧。增量/位置/速度单位分开,QP 与 objective 一起更新并做梯度对拍。
- [ ] 新目标用无量纲尺度,预先固定小型权重对照(关闭、0.1、1.0);若归一化定义不适用,运行前先写明替代值及理由。单次只改该目标,不同时改变跟踪权重、走廊和验收速度门。

接受条件:达到 §9 质量要求且保持任务与运动幅度,不能靠停住机器人改善认证。各变体都评估完整六段,不为每个 demo 配不同权重。与 probe 组合仅在两项单独影响明确后运行。

### 7.3 仍失败时的有界恢复

仅在正确性、probe 与稳定性对照后仍 <4/6 时触发,不预先全部实现。

| 新证据 | 最小下一步 | 限制 |
|---|---|---|
| 已接受状态与参考误差逐步增长,末帧需大步追赶 | 原权重与 prediction 权重乘 0.5 的单项对照;必要时参考驱动的缓跟随 | 所有状态仍满足原任务门,检查累计漂移;不推断 sub12 必然属此类 |
| 固定前帧使局部路径无法恢复,单帧 probe 求解仍失败 | 离线短窗口联合修复,先 3 帧、必要时 5 帧;窗口前边界固定,箱轨迹固定 | 复用 OSQP/现有残差与约束;重放接触状态并检查全部内部/入口转移,成功后继续顺序处理;另记预算成本 |
| 新证据明确定位首帧贴近地板影响后续 | 非负首帧下界或软拉入单项消融 | 先验证 t=0 真输入与可行性,不能因 t=11/34 失败自动启用 |
| 原始输入本身存在不可恢复跳变 | 原始站点/箱运动证据,独立预注册筛查 | 候选穿透不是输入证据;不删分母,不因筛掉一段把 3/6 改成达标 |

短窗口是离线教师策略,不能宣称为在线生成器性能改善。每类完成一次预注册对照后仍未改善,记录负结果并更新具体设计;不重复无依据地加迭代、扩大网格搜索或提前跑 312 段。
