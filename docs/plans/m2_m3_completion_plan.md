## 1. 目标与执行边界

核心顺序为:修复器正确性 -> 六段诊断 -> 24 段标定 -> 全量教师重生成 -> 模型重训。

- M0/M1 已有验收记录;M2 机制完成但鲁棒性与性能未达标;M3 模型与 pilot 已完成,教师数据收尾未完成。M4 已有评测工具但最终验收不属于本方案范围,另行规划。
- 优先修复已实证的碰撞对漏激活和插值走廊问题,再判断是否需要跟踪策略或输入筛查。不得预设修复后一定达到某个接受率。
- 本轮正确性修复不放宽 strict 碰撞、限位、速度及手足验收容差。任务质量门的重标另行留痕,不能与实现修复混为同一实验。
- 原始资源只读,新产物写独立目录;旧报告保留版本说明。relaxed 仅作为诊断对照,不计入主方案 §10.1 达标。
- 所有拒绝和预注册排除均保留在原始输入清单中。可另报筛选后比例,但不能替代原始分母结果。
- 暂不启动 M5 回放、M6 RL 接口或新机器人支持。未经实测不承诺工期、训练饱和时间和加速比。
