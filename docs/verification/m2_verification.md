## 2. 开发中发现并修复的关键数值 bug(防回归记录)

1. **穿透时距离梯度符号翻转**:`d = s·n̂·(p2−p1)`,s=±1 按分离/穿透——修复前每个分量恰好差一个负号,QP 把脚往地里推。FD 对拍逐分量一致后修复。
2. **mesh 几何的旋转项缺失**:最近点距 geom 中心 ~10cm,`ω×r` 主导梯度;补 `geom_point_jacobian_35 = Jp − skew(r)·Jr`。
3. **信赖域行号错位**:z_prev=None 时速度行(35 行)不追加,slack 装配硬编码 `[64:99)` 排除了碰撞行而非信任域行 → 全部 slack QP 假性不可行;改为显式追踪行号。
4. **违反度归一化尺度**:单侧行按界宽(~1e9)归一使 21mm 穿透不可见;改为按各行自身容差(碰撞 2mm、速度行宽、锚定 tol)归一。
5. **merit 权衡失衡**:D 归一化预测目标中抬根 5mm 代价 ~1.0,而 0.6mm 违反按米归一仅 ~0.0006×μ——优化器理性选择违反;由 4 的修复一并解决。
6. **箱-地伪影进入约束集**:扫描箱凸包外推箱底 ~7mm,`box_ground` 对(J≡0)使紧 QP 恒不可行;修复器约束与终检均按输入所有权排除(数据筛选负责上报)。
7. OSQP 对 primal infeasible 返回垃圾 x(|xi|~1e9),按状态路由到 slack 恢复,不裁剪使用。
8. 锚点候选取自预测几何(违反 §8.4"从被接受状态建立"),与速度行立即矛盾;重构为接受后建锚。

## 4. M2 验收实验(`scripts/eval_repair.py`)

**教师整段修复(P1,6 段 × 120 帧)**:接受率 **0%**(前缀重修亦不可行)。失败成因:教师支撑期滑移(~0.3m/s)与软抓取漂移超出"冻结锚点 + 任务门槛"的可修复范围——**教师筛选结论:不可直接作为修复输入,须 M3 数据准备重生成/清洗**(与 M1 教师质量量化一致)。逐段诊断记录于 repair_eval.json。

**合成支撑基(P1c,站立 + 双脚支撑锚定,6 种子)**:4/6 通过(基 0-2 全帧跳过,基 5 全修)。

**可恢复扰动集(P2,15 次)**:

| 扰动 | 接受率 |
|---|---|
| 关节噪声 σ=0.02 rad | 2/3 |
| 关节噪声 σ=0.05 rad | 1/3 |
| 关节噪声 σ=0.10 rad | 0/3 |
| 根偏移 3cm + 6° | **3/3** |
| 单帧尖峰 0.3 rad | **3/3** |
| **合计** | **9/15 = 60% < 95% 目标** |

**不可达(P3)**:0 误受(2/2 正确拒绝)。

**计时**:修复帧均值 ~310ms/帧(目标 <50ms/帧未达;OSQP 已调优,瓶颈为 MuJoCo 几何查询 × SCP 迭代;持久 QP 工作区与活跃对增量更新留作优化)。

### 未达标成因分析

噪声类失败的机制:σ≥0.02 的腿部噪声使 sole site 偏移 1-4cm,超出 ±1cm 锚定带;修复须在冻结脚(0.67mm/帧)与拉回预测之间调和,深违反帧在 15+15 迭代内 merit 收敛不足。根偏移/尖峰类(整体可行、局部违反)3/3 通过,说明机制本身正确,**短板在深违反 + 硬锚定组合下的收敛预算与步长策略**。

### 达标路径(后续工作,按优先级)

1. 深违反帧的多起点重启(从 z_prev 与 z_pred 双起点取优,已有雏形);
2. 锚定带内渐进收紧(先 ±3cm 后 ±1cm 的两段式接受);
3. 持久 OSQP 工作区 + 活跃对增量维护(同时解决计时);
4. 若上述仍不足:与方案 §8.5 一致,把"锚定不可满足"的片段交给局部纯优化回退(M2 未实现该路径,M3 补)。
