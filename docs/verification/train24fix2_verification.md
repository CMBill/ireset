### 3.3 机理

1. **越界幅度全部 µm 级**(0.4–27 µm 超 0.866 mm 界):求解器把候选压到 C2 边界后,与走廊/任务/其余行的联合需求使最后 µm 无法闭合(QP merit/eps 交互),三级尝试全部 `infeasible`。
2. **范数合格但分量越界的对角效应**:失败候选的真实范数速度 0.031–0.045 m/s(均 < √3·v_row=0.0450,更 < 0.05)——单轴分量(如 0.02601 m/s)超 v_row=0.02598 而范数仍合格。§4.1 的蕴含只保证"满足行⇒范数合格",反向不成立;逐轴行在斜向运动处严于验证器范数门。
3. **sub3/sub12 在 t=1 双侧启用**(帧 0 手已在箱上,prev 场景距离 ≤8 mm):拉入豁免从未适用,行从片段开局绑定全部携带期(含参考换 grip 调整)——2026-09-15 负结果的冲突模式在"开局已抓握"形态下无法被区间判据避开。sub10/sub7/sub8 分别在 16–29 帧启用后数帧内同样触发。
4. **sub16(唯一保留)质量不降反升**:task p95 与 B 逐位相同(0.101574);右侧认证∩参考交集 0→15 帧、最长 0→15、近接 13→16——C2 在可行处的机理(消除尖峰碎裂)按预期生效。
