## 1. 方法

`scripts/regenerate_teachers.py` + `RepairConfig.regen_mode`:

- **热启动**:旧教师轨迹作为 prediction;参考条件(人体关键点 + 箱轨迹 + 参考调度)不变。
- **主动手部接触**:参考抓取区间内,该侧**最近的**手部几何体对箱承载主动上界行(接触 := 最近面贴上,与验证器 min-over-geoms 同口径;行绕过 48 对截断)。非抓取帧保持 P0 逐对几何分类。
- **闭合走廊**:上界 = max(8mm, 上一接受帧距离 − 0.15 m/s×dt)——区间首帧硬上界单帧不可行(4-5cm 手部笛卡尔运动),无界伸臂又触发转移检查。
- **目标**:预测项(全身结构稳定)+ mesh(0.1,人体关键点)+ **手部关键点专项目标**(weight 25/scale 0.02,机器人手部 site 质心追**表面外投 8mm 的**参考人体手质心;抓取期人体手箱体系准静态)。手部点目标不可由 mesh 项兼任——提 mesh 权重会连带跟踪人体脚部滑动、破坏准静态脚模型(mesh≥0.3 全部不可行,实测)。
- **无手部点锚**:±10mm 箱体系锚在箱旋转下被悬浮跟踪目标反复顶出界(0.1-1mm 边际不可行);接触由硬间隙行维持,姿态稳定交给跟踪,由 strict 验证器的锚漂门裁决。
- **筛选**(keep):strict 独立验证通过 + 每个有参考抓取的侧**物理接触覆盖 ≥50%**(参考抓取帧中最近手部几何距箱 <10mm 的比例);认证区间覆盖(interval recall)作报告项。
- 产物:teacher 布局 NPZ(qpos 四元数在前/human_joints/fps,与 `load_teacher_npz` 兼容)+ 溯源报告(git rev、配置、逐段筛查行)。

## 2. 过程中发现并修复的存量问题

1. **slack 松弛变量缺 s ≥ 0 下界(M2 期存量 bug)**:`build_qp(slack=True)` 的松弛变量无下界,+penalty 线性项驱动 s 变负(实测 −51)——QP 产出破坏性步长(步后违例 26)。在易满足系统上负 s 的"过度收紧"客观上充当安全余量,故长期未暴露;近不可行系统(走廊帧)直接致命。已加恒等行强制 s ≥ 0(`scp.py`,测试锁定)。
2. **插值下探盲区**:诚实 slack 移除上述"隐性余量"后暴露——线性关节插值的中间态可比两端点低 ~0.3×step²(实测 0.8mm@7.9cm 步、5.6mm@16.6cm 步),逐帧解贴约束边界、转移探测必然擦界。新增**步长平方标度的求解器带余量** `min(6mm, max(0.5mm, 0.3·motion²))`(帧级,验证器口径不变)。
3. **手部门从未对"移动箱上的手"标定**:参考人体自身在抓取期的箱体系速度 p50 0.042 / p95 0.758 m/s(瞬时换 grip 尖峰),区间内锚漂 p90 18.4mm;原门(0.02/0.02/0.01,按脚模型对称继承)连参考人体都排除。**按参考分布重标**(protocol.yaml 记录旧值):`hand_anchor_error_m` 0.01→**0.02**、`hand_relative_speed_mps` 0.02→**0.8**(反甩脱门,认证交给锚漂)、`hand_entry_speed_mps` 0.02→**0.05**。脚部门不动(有真实数据标定)。
4. 负结果:手部箱体系**速度硬行**(模仿脚部速度行)与参考换 grip 运动(p90 15mm/帧)结构性冲突,距离门控激活又在阈值处抖动——已禁用(`regen_hand_speed_mps: 0.0`),代码与注释保留。
